Use it

Works where your results already are.

from paretolens import Front

res   = minimize(problem, NSGA2(pop_size=100), ("n_gen", 200))
front = Front.from_pymoo(res, names=["cost", "co2"])

front.summary()                 # extremes, knee and best compromise
front.to_html("report.html")    # the interactive report
# one row per solution, one column per objective
front = Front.from_csv("results.csv", objectives={"cost": "min", "energy": "max"})

# objectives and decisions on separate sheets, matched by id
front = Front.from_excel("results.xlsx", objectives={"cost": "min", "co2": "min"},
                         sheet="objectives", variables_sheet="decisions", on="id")
$ paretolens results.csv  --min cost --min co2 --max energy -o report.html
$ paretolens results.xlsx --sheet objectives --min cost --max energy --negate energy
  • front.knee()

    The point where improving one objective starts costing a lot in the others.

  • front.topsis(weights)

    A score for every solution under your own priorities.

  • front.tradeoff(i, j, a, b)

    How much of one objective you give up per unit of another.

  • front.nondominated()

    Drops dominated rows if you load a whole population.
